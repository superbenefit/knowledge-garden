# Group Primitives 

These [primitives](/content/tags/Primitives.md#) are the fundamental building blocks that we use to create purpose-aligned [networks](/content/tags/Networks.md#) of small autonomous teams.

The term "primitive" is used in many different contexts to mean slightly different things. In this context we use "[primitive](/content/tags/Primitives.md#.md#)" to describe these 4 fundamental building blocks out of which network [governance](/content/tags/Decentralized%2520Governance.md#) and operational structures can be built.

## Entities & Agreements

Network theory defines [networks](/content/tags/Networks.md#.md#) as being made up of nodes (the entities or objects in the network) and edges (the relationships or interactions between those nodes).

For designing [governance](/content/tags/Decentralized%2520Governance.md#.md#) and operational structures, we define nodes and edges as Entities and [Agreements](/content/tags/Agreements.md#). Entities being the structures within the DAO (or other decentralized network) and agreements being relationship infrastructure, the commitments and [responsibilities](/content/tags/Responsibilities.md#) that are agreed upon between autonomous actors in the network.

To allow for [governance](/content/tags/Decentralized%2520Governance.md#.md#) systems to be easily designed, we lean on these 4 structures. Each one has enough definition to be useful in design, but can be configurable in a multitude of ways to allow for many different governance approaches and patterns to be implemented.

## Phase & Scale

The [primitives](/content/tags/Primitives.md#) are designed to evolve through the different stages of [group-phase](/content/artifacts/guides/dao-primitives-framework/group-phase/Group%2520Phase.md#) and also deliver on different [group-scale](/content/artifacts/guides/dao-primitives-framework/group-scale/Group%2520Scale.md#) requirements of the [governance](/content/tags/Decentralized%2520Governance.md#.md#) and operational system being designed.

## State

Each [primitive](/content/tags/Primitives.md#.md#) has a concept of state, an internally documented, externally visible description of the entity or agreement's [Purpose](/content/tags/Purpose.md#), [Practice](/content/tags/Practices.md#), and [Progress](/content/tags/Progress.md#), so that this can be seen and understood independently by anyone in the [network](/content/tags/Networks.md#.md#.md#).

This [transparency](/content/tags/Transparency.md#) allows for decentralized [coordination](/content/tags/Coordination.md#) across the network. At any point in time the whole of the [governance](/content/tags/Decentralized%2520Governance.md#.md#) and operational structure (all of its entities and [agreements](/content/tags/Agreements.md#.md#)) can be seen and understood. This allows the network to manifest as a coherent whole, while allowing for autonomy for the entities that make it up.
